# GitHub Star Date Display

A userscript that shows when you starred a GitHub repository as a floating overlay at the bottom-right corner of the viewport.

## Install

Install from [Greasy Fork](https://greasyfork.org/en/scripts/564752-github-star-date-display).

## How it works

When you visit a starred repository on GitHub, the script fetches your starred repos search page (`/stars?q=...`) and extracts the date you starred it. No API token or authentication needed. Results are cached locally to avoid repeated requests.
